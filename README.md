# Amazon Store Sales Dashboard – Power BI

A Power BI dashboard visualizing Amazon store sales data to track performance, analyze top products, monitor revenue trends, and gain customer insights. Interactive visuals and filters make it easy to explore sales patterns and support data-driven decisions.

# Tools:
Power BI, DAX, Data Visualization
Key Features: Sales overview, product & category analysis, customer insights, revenue trends
